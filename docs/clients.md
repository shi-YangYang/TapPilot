# 客户端实施与验收

电脑是唯一任务主控：用户在电脑配置 LLM、输入任务并查看结果。手机只作为被控端，提供连接、权限、状态和紧急停止。控制通道为 USB（ADB）或局域网扫码配对。

## 运行边界

桌面：Electron 受限 renderer → main process → LLM runtime / 手机工具适配 → 配对 WSS（或开发 USB bridge）→ Android 无障碍。WSS 模式不调用 ADB。

手机：USB RPC / 配对 WSS → 本 App 无障碍执行器 → 当前 App 原生 UI。手机不调用 LLM、不配置模型密钥，也不独立规划或运行任务。Android 和厂商后台限制仍需实际设备验证。

MCP 保留给外部 Agent。桌面客户端不把 Codex 当作运行时，也不把模型 API Key 写入 MCP 工具输入。工具结果和第三方界面文本始终作为不可信数据。应用本身的配置、授权和恢复界面继续受保护，不能由手机自动化接口点击。

桌面客户端的 `tap_element` 是电脑侧适配能力，复用 Android 已有 `swipe` 协议，因此不要求更新已安装的手机端。外部 MCP 的 `click_element` 仍为原生无障碍点击，从 v0.3.14 起在原动作字段旁附带观察结果；设备协议未改。

## 模型协议

电脑端实现 Chat Completions 兼容接口，用户在桌面客户端配置 API 地址、模型名和密钥。Base URL 自动补 `/chat/completions`；已填写完整 endpoint 时不重复补。支持工具 schema、assistant tool_calls 和关联 tool_call_id 的结果回传。协议依据 [官方 Chat Completions 参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)，不假定所有厂商原生 API 或模型均兼容。

客户端验证响应结构、工具 allowlist 和参数。网络失败、未知动作结果、模型格式错误均不自动重试变更。轮次、执行时间、请求/响应与上下文大小有界；取消后不再派发后续动作。高风险提交停止并交用户手工完成，不提供模型可调用的自批准机制。

模型页“高级设置”可调整单次输出上限，对应 Chat Completions 的 `max_tokens`。上限不等于固定生成量；提高预算能减少过早截断，但可能增加延迟及费用，且受服务端输出与上下文容量限制。当前不猜测第三方网关的思考模式参数，也不自动重试或降档。

## 效率验收

1. 任务启动宿主预读 UI，首个模型回合可以决策，不必先请求读取。
2. 单个 `act_and_observe` 完成一次原生动作、事件等待、新 UI 读取：设备 RPC 数量由三次降为一次。
3. 传输层去掉空字段与默认 false 属性；模型层额外裁剪空布局、去除重复描述与动作目标副本，保留节点 ID、可操作祖先、边界、安全状态及所有可见文字。模型树的 parentId 指向最近保留祖先，rid 和 class 的缩写规则在系统提示中说明；执行器继续使用原始树。
4. 历史快照被后续快照替换，不把所有完整 UI 一直重复发送。
5. 动作返回界面不变或可恢复快照错误时，电脑最多补读一次；同批模型请求已经读取完整界面则不补读，不重放动作。自动补读遵循原有取消、超时与停止检查。
6. 显示累计模型请求字节、压缩前后 UI 字节与自动补读次数（不含首次预读）。这些是每次请求求和，包含重复发送的当前 UI；压缩比例对比同一次请求的原始与精简 UI，不含工具定义与提示词。
7. 显示 modelMs、toolMs、totalMs、modelRequests、toolCalls；组合工具返回 actionMs、waitMs、observationMs、totalMs。只使用本地单调时钟，不跨设备相减墙上时钟。

重复保护区分读取和变更动作：同一只读查询连续三次结果不变才停止；启动时的预读不占模型读取次数。变更动作最多连续尝试两次，更新快照引用或等待时长不能绕过；局部查找结果变化不会清空动作历史。完整界面有变化时重新计数，但界面变化不等于用户任务取得进展，仍需模型核实目标。原生点击无效时，模型应先等待或读取；若新树确认目标唯一且点击没有效果，可考虑一次位于当前目标范围内的触控手势，受保护操作与急停限制仍然有效。

合成测试证明协议和往返减少，不代替真实模型决策能力、OEM 兼容性或完整任务速度实测。

## 仍需真实外部状态的检查

在电脑配置用户自己的模型服务后，分别通过 USB 和扫码连接，以相同“设置 → 电池”任务测试，确认桌面客户端无需运行 Codex 即可自主完成。API 密钥只在电脑客户端填写，不发送到开发对话，不保存到仓库或测试夹具。

两种连接均需要电脑保持运行，以及用户在手机手动开启服务和允许自动化。USB 需要 USB 调试授权；扫码在同一局域网运行，不需要开发者选项、ADB 或数据线，也可粘贴配对链接连接同一无线通道。开发自动化不能通过写系统设置、批准 socket 或伪造用户操作开启权限。
