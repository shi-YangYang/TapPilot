    使用服务商提供的地址；本机服务可填写 http://localhost:端口/v1。

    通过 macOS 钥匙串加密保存。同一服务地址留空保留密钥；更换域名或端口会清除旧密钥。本机无鉴权服务可留空。

    01 / 独立运行

    不需要 Codex。

    TapPilot 自己管理任务循环。模型负责判断，客户端负责执行、验证和停止。

    02 / 数据流向

    由你选择模型服务。

    任务及必要的手机界面信息会发送到此地址。API Key 只保存在本机，不会回传到界面。

    03 / 能力差异

    连接成功，只是第一步。

    不同模型的工具调用和界面理解能力不同。先用“读取当前界面”验证实际效果。

    控制权始终在你手中

    任务随时可以停止。

    取消会结束当前任务；紧急停止还会请求手机锁定自动化操作，直到你手动恢复。

    关于当前连接方式

    USB 是开发通道。

    这个桌面版本复用现有 USB 控制链路。手机独立客户端可以直接连接模型服务，在手机上运行任务。
